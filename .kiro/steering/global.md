# b-answer システム概要

本プロジェクトは、**制限時間付きの択一クイズをリアルタイムで出題・回答・集計する Web アプリケーション**である。  
Nostr を基盤とした分散イベント配信と、Cloudflare を用いたサーバーレス構成を採用する。

---

## システム全体構成

本システムは以下の 3 レイヤーで構成される。

1. **サーバー部（Nostr Relay）**
   - `strfry` による Nostr リレー
   - イベントの **receivedAt（到達時刻）を記録・返却**する拡張機能を持つ

2. **サーバーレス・バックグラウンド部（Cloudflare Workers / KV）**
   - 認証（NIP-98）
   - 回答鍵・問題鍵の生成および KV 管理
   - サーバー部への receivedAt 問い合わせ窓口

3. **サーバーレス Web アプリ部（Cloudflare Pages / SvelteKit）**
   - 主催者・プレイヤー向け UI
   - Nostr リレーと Workers を用いたクライアント主体通信
   - レスポンシブ対応

---

## ゲームの基本概念

- **ゲーム**：1つの大会
- **主催者（Game Master）**：ゲーム作成・出題・進行・採点を行う
- **プレイヤー**：ゲームに参加し回答するユーザー

---

## セキュリティ・暗号化設計

- **回答鍵**
  - 1ゲーム共通方式
  - プレイヤーごとに個別付与
  - 回答の暗号化・主催者による復号に使用

- **問題鍵（非公開ゲーム用）**
  - 主催者と参加プレイヤーのみ取得可能
  - 問題・正解の暗号化配信に使用

---

## UI 構成の概要

### 主催者 UI

- TweetDeck 風マルチカラム構成
- 主な機能：
  - 問題作成・下書き管理
  - 出題・プレビュー・ディレイ設定
  - 回答状況・得点・回答権管理

### プレイヤー UI

- 公開ゲーム・参加済みゲーム一覧
- 回答画面：
  - 問題文 / タイマー / 選択肢 の3分割
  - 6択の回答ボタン
  - 回答不可時はシャッター演出

## Nostr リレー方針

- メインリレー：`relay.tiltpapa.tv`
- 冗長保存対象：
  - プロフィール
  - 下書き
  - 成績データ
- 併用リレー例：`yabu.me`, `nos.lol`
