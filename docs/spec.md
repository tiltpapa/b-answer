# 制限時間付き択一クイズ Web システム 仕様概要

本システムは、**制限時間付きの択一クイズを出題・回答・集計するWebアプリケーション**である。  
アーキテクチャは以下の **3つのセクション** から構成される。

- サーバー部（Nostr リレーサーバー）
- サーバーレス・バックグラウンド部（Cloudflare Workers / KV）
- サーバーレス Web アプリ部（Cloudflare Pages）

---

## 用語定義

| 用語 | 定義 |
|------|------|
| ゲーム | 本システムを用いて行われる1つの大会・イベント |
| 主催者 | ゲームを作成・開催する人物。出題者、Game Master |
| プレイヤー | ゲームに参加し回答する人物。回答者 |

# 1. サーバー部（Nostr リレー）

## 概要

- 通常は **Nostr リレーとして動作**
- 一部イベントについて、**Workers から問い合わせがあった際に receivedAt（受信時刻）を返す**
- リレー実装には **strfry** を使用  
  - https://github.com/hoytech/strfry/
- **プラグインを作成し、receivedAt 専用のDBを追加管理**
  - 参考: https://github.com/hoytech/strfry/blob/master/docs/plugins.md

## receivedAt 管理用DB構造

以下の情報を保存する。

- イベントID
- receivedAt（到達時刻）
- pタグ, eタグが付いている場合はそのID

# 2. サーバーレス・バックグラウンド部（Cloudflare Workers / KV）

## 役割

- **Nostr通信以外のデータの中継窓口**
- Cloudflare KV および サーバー部 と通信
- 認証方式は **NIP-98**

---

## 鍵管理機能

### 回答鍵（プレイヤー用）

- **1ゲームにつき共通鍵方式で管理**
- 各プレイヤーごとに個別生成
- 用途：
  - プレイヤー：自分の回答鍵のみ取得し、**自分の回答を暗号化**
  - 主催者：すべてのプレイヤーの回答鍵を取得し、**回答を復号可能**
- 保存先：Cloudflare KV

### 問題鍵（非公開ゲーム用）

- 非公開ゲームに対して生成
- **主催者・参加プレイヤーの双方が取得可能**
- 用途：
  - 主催者：問題文・答えを暗号化して配信
  - プレイヤー：問題文を復号して表示

---

## receivedAt 取得機能

- Workers は、指定された **イベントIDに紐づく receivedAt 値をサーバー部へ問い合わせる**

# 3. サーバーレス Web アプリ部（Cloudflare Pages）

## 技術構成

- フレームワーク：**SvelteKit**
- CSS：
  - 基本：**beercss**
  - 問題表示画面のみ **独自CSS**
- 動作方式：
  - 原則 **クライアントサイド処理**
- **レスポンシブ対応**
- UIは **主催者用・プレイヤー用で大きく異なる**

---

## Nostr 通信方針

- 主リレー：`relay.tiltpapa.tv`
- 冗長保存対象：
  - プロフィール
  - 下書き
  - 成績データ
- 保存リレー例：
  - `yabu.me`
  - `nos.lol`
- 各種Nostrイベント定義、適宜編集する：
  - `docs/event.md`
  - `docs/format.md`　(データフォーマットを定義)
- `nostr-wasm`を使用しNostr署名/検証を高速化

#### 問題表示部

- 3:4表示
- 構成1 問題表示(参考(4択選択肢テキスト): `docs/multiple.md`)：
  1. 問題文
  2. タイマー
  3. 選択肢

  3. 秒数(コンマ2桁まで表示)

  1. チャンピオンが回答した選択肢(選択肢記号のみ)
  2. 正解の選択肢

# 7. 補足仕様

- **7択以上の問題は当面想定しない**
- ユーザーが作成したコンテンツを表示するため、**XSSのようなSNSクライアントと同様のセキュリティリスク**を考慮する
- ランキング表示の演出:
  - 一度に表示する人数を指定、順位範囲を指定できるようにする
  - 上位n名、または下位n名を主催者のタイミングで公開する
      - そのn名を一人ずつ公開することもできるようにする
- ボーナスクイズのチャンピオン回答の演出:
  - チャンピオン回答の表示、正答の公開を主催者のタイミングで公開
    - 正答は一つずつ公開し、最後の2つは一気に公開
- 不正解したときのタイムは成績の合計には加算しない
- 動作確認:
  - ローカル環境で実行可能
  - ブランチごとにデプロイできるようにする(サーバレスWebアプリ部)
    - 例: `dev`ブランチの場合、`example.com/dev/`配下にデプロイ
